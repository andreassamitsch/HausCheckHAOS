# Kiosk wake bridge (experimental)

Voice Satellite 2026.9.13; assign assist_satellite.family_dashboard_tablet in Kiosk Satellite, enable native local wake word, choose Okay Nabu (microWakeWord). Register kiosk-wake-bridge.js as a Lovelace module resource. It intercepts native wake events only on the assigned kiosk and Family Dashboard, releases the native mic, stops the Voice Satellite engine, then opens the existing Live Voice route. On returning, the engine restarts. The manual shortcut remains unchanged; on the assigned active kiosk the bridge coordinates mic ownership. No continuous ChatGPT connection. Wait for the existing green ready indicator / ready chime before speaking; this version does not transfer native pre-roll to WebRTC. On unsupported clients ordinary Voice Satellite behavior remains; fallback pipeline is Home Assistant. Test real Android native event, playback, release and rearm before relying on it. Rollback: remove this resource; the app is unchanged.
